# M4.2 demonstration runbook

Use `data/demo-dossiers/m4-2/regbridge-m4-2-public-standards.zip` in both Analyzer and Baselines.
The ZIP is public synthetic data generated by `scripts/generate_m4_2_dossier.py` and contains no
reference labels, expected decisions, benchmark identifiers, fixture identifiers, or adjudication
rationale.

The Analyzer profile panel should show profile
`fda-cder-ectd-322-public-standards-profile-v1` version `1.0.0`, sequence root
`synthetic-application/0000`, both pinned DTD identities with validation `passed`, one warning for
the inferred index version, and three `EVALUATED_WITH_APPROVED_POLICY` documents. The three
documents preserve the existing structural, metadata, and stale-applicant demonstration signals.

Baselines reuses the same parsed inventory and runs B0, B1, B2, and RegBridge. It reports native
outputs and coverage, not benchmark metrics, rankings, winners, or correctness claims.

Run `scripts/m4-2-verify.ps1` twice before the demonstration. This milestone validates only the
bounded input envelope against the pinned DTDs and selected parser criteria. It is not complete
FDA validation, submission-readiness assessment, production conversion, or eCTD v4.0 generation.
