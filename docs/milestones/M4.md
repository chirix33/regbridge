# M4 - Demonstration dashboard, guided workflow, and presentation QA

M4 consumes the completed M3 artifacts as immutable inputs. It does not modify the frozen
benchmark, labels, prompts, schemas, live results, Phase 2 manifests, or fixture-validation
outputs.

## Delivered surface

- `data/presentation/m4/m4-phase2-20260901T170811002109Z-v1/snapshot.json` is a sanitized,
  digest-verified presentation snapshot derived from the frozen Phase 2 run.
- `GET /api/v1/presentation/m3`, `/cases`, `/cases/{case_id}`, and `/api/v1/demo/presets` expose
  read-only typed presentation data. They accept no filesystem paths and perform no recomputation.
- `/evaluation` displays the held-out 12-case Phase 2 dashboard offline from the snapshot. B0, B1,
  and RegBridge repetitions remain separate; B2 appears once as genuine deterministic output.
- `/demo/case-a`, `/demo/case-b`, and `/demo/case-c` provide the guided fixture-mode workflow with
  reset, current-operational guard, evidence details, graph table, and persistent disclosures.

## Presentation boundaries

The dashboard states that it is derived from run `m3-live-phase2-20260901T170811002109Z`; results
are displayed, not recomputed. FDA forward compatibility remains `not_operational`.
`expert_validated` remains `false`. Live outputs claim configuration and artifact reproducibility
only. Fixture-mode determinism claims are unchanged.

BM25 recall@3, precision@3, and MRR are displayed in a separate retrieval panel. Unsafe-FNR and
review-bypass are shown with equal prominence. Wilson values are descriptive only; family-clustered
intervals remain exploratory with no independence or significance claim.

Graph explanations disclose the implemented graph schema v2:

```text
FINDING -> CITES -> DOSSIER_EVIDENCE
FINDING -> ABOUT -> KEYWORD
DOSSIER_EVIDENCE -> OBSERVES -> KEYWORD
```

The originally planned discriminated evidence union was replaced by one `DOSSIER_EVIDENCE`
occurrence node type plus `evidence_kind`; this is presentation-visible because it is a paper
disclosure item.

## Verification

Run:

```powershell
.\scripts\m4-verify.ps1
```

The verifier validates the snapshot digest, checks protected M3 files before and after execution,
and runs the three demo presets twice in fixture mode. The two fixture runs must produce identical
decision, action, evidence, graph, and timestamp-free trace digests.

For browser checks after Playwright browsers are installed:

```powershell
npm --prefix frontend run test:e2e
```

Screenshots and video notes are in `docs/DEMO_M4.md`.
